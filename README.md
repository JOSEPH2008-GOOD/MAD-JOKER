# Joseph Designs — Portfolio

A simple, responsive portfolio website built with HTML, CSS and JavaScript.
The brand blue (`#0072AB`) is taken directly from the logo.

## Open it
Just double-click `index.html` — no installation needed.

## Customise
- **Projects:** edit the `projects` list at the top of `script.js`. Put your design images in `assets/` and set `image: "assets/your-file.jpg"`.
- **Email for the contact form:** change `MY_EMAIL` in `script.js`.
- **Contact details & social links:** edit the Contact and Footer sections in `index.html`.
- **Stats / skills:** edit the About section in `index.html`.
